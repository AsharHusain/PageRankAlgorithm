Q6 · Parallelizable blocks — Foster PCAM

Each destination update is independent within an iteration once current ranks and total dangling rank are known. Iterations depend on one another; all processes need the same convergence decision.

Partition and mapping (N=10, P=4): all processes store the same graph and full rank vector, but update only their contiguous range. Process 0: vertices 0–1 [0,2); process 1: 2–4 [2,5); process 2: 5–6 [5,7); process 3: 7–9 [7,10). The owner scans incoming CSR edges for its destinations.

Q7 · MPI pseudocode

MPI_Init; get rank p and process count P
Build and validate the same graph on every process
Set owned range [begin,end); initialize ranks to 1/N
MPI_Barrier; start = MPI_Wtime()
for iteration = 1 .. 10,000:
    local_dangling = sum owned dangling ranks
    D = MPI_Allreduce(local_dangling, SUM)
    base = (1-d)/N + d*D/N
    update each owned destination using incoming edges
    MPI_Allgatherv(next_local, next)
    local_L1 = sum owned |next[v]-rank[v]|
    L1 = MPI_Allreduce(local_L1, SUM); swap(rank,next)
    if L1 < 1e-6: break
local_elapsed = MPI_Wtime() - start
MPI_Reduce(local_elapsed, MAX, root=0)
Rank 0 prints result; free memory; MPI_Finalize

Q8 · N10 demonstration — first iteration

The graph has N=10, E=11. Vertex 5 has no outgoing edge; vertex 9 is isolated. Separate clusters are not connected.

Edges: 0→1, 0→2, 1→2, 2→0, 3→0, 3→2, 4→3, 4→5, 6→7, 7→8, 8→6.

Q10 · Time and space complexity

Let N be vertices, E edges, I iterations, P processes. Serial work is O(I(N+E)); balanced MPI computation is approximately O(I(N+E)/P) per process. Each iteration adds two scalar Allreduces and an Allgatherv of N ranks to every process. Imbalance and communication can limit speedup.

Each process stores replicated CSR and full rank vectors: O(N+E) memory per process, O(P(N+E)) total. The graph is not distributed. Timing starts after a barrier, before the loop; reported elapsed time is the maximum across processes.
