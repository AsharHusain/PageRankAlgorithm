Q6. Parallelizable blocks — Foster’s PCAM methodology

For a fixed iteration, the new rank of each destination is independent after the previous rank vector and total dangling mass are known. Iterations are dependent: the new vector from iteration k is required by iteration k+1. The global L1 convergence test also requires a reduction before all processes can make the same stop/continue decision.

Partitioning. Split destination vertices into contiguous, nearly equal ownership ranges. For process p of P, the range is [floor(Np/P), floor(N(p+1)/P)). The independently parallel tasks are the incoming-edge rank sum and new-rank calculation for each owned destination; owned vertices also contribute to local dangling mass and local L1 error.

Communication. Before updates, MPI_Allreduce(SUM) combines local dangling mass. After local destination updates, MPI_Allgatherv assembles the complete next rank vector on every process. A second MPI_Allreduce(SUM) combines L1 error for the common convergence decision. On exit, MPI_Reduce(MAX) reports the maximum elapsed process time to rank 0.

Agglomeration. Group all destination updates and CSR incoming-edge scans in a process’s range into one local work block per iteration. Communicate once at iteration boundaries rather than per edge or vertex. The program retains a replicated graph and rank vectors; this agglomeration therefore groups computation, not graph storage.

Mapping. Map each contiguous block to one MPI process. For the N=10, P=4 demonstration below, the ownership blocks are [0,2), [2,5), [5,7), and [7,10). Each process builds/stores the same graph and full current vector, and computes only its owned destinations.

Q7. MPI pseudocode

The algorithm below reflects the collective order and timing scope in c/mpi_pagerank.c (c/mpi_pagerank.c) and the shared constants in c/shared_graph.h (c/shared_graph.h): damping d=0.85, L1 tolerance 1e-6, and maximum 10,000 iterations.

MPI_Init; obtain process rank p and process count P
Every process constructs and validates the same incoming-CSR graph G(N,E)
begin = floor(N*p/P); end = floor(N*(p+1)/P)  // owned destinations [begin,end)
Initialize rank[v] = 1/N for every vertex; allocate next and local_values
For every process q:
    counts[q] = floor(N*(q+1)/P) - floor(N*q/P)
    displacements[q] = floor(N*q/P)

MPI_Barrier
start = MPI_Wtime()
for iteration = 1 .. 10,000:
    local_dangling = sum(rank[v] for v in [begin,end) when out_degree[v] = 0)
    dangling = MPI_Allreduce(local_dangling, SUM)
    base = (1-d)/N + d*dangling/N
    for each owned destination v in [begin,end):
        incoming = sum(rank[u]/out_degree[u] for each CSR edge u → v)
        local_values[v-begin] = base + d*incoming
    MPI_Allgatherv(local_values, counts, displacements, next)
    local_error = sum(abs(next[v]-rank[v]) for v in [begin,end))
    error = MPI_Allreduce(local_error, SUM)
    swap(rank, next); iterations = iteration
    if error < 1e-6: break

local_elapsed = MPI_Wtime() - start
elapsed = MPI_Reduce(local_elapsed, MAX, root=0)
Rank 0 prints N,E,iterations,elapsed,status,final_L1_error and optional ranks
Free allocated memory; MPI_Finalize

Q10. MPI time and space analysis

Let N be the vertex count, E the edge count, I the number of iterations, and P the process count. Serial work is O(I(N+E)); OpenMP shares the graph and parallelizes vertex scans and updates, subject to thread overhead. In MPI, each iteration scans owned vertices for dangling rank and L1 error and scans the incoming edges of owned destinations. With balanced vertex and edge work, local computation per process is approximately O(I(N+E)/P). If incoming-edge work is uneven, contiguous vertex ranges can have unequal loads; elapsed iteration time is determined by the slowest process. The I iterations remain sequentially dependent.

Each MPI process stores the complete incoming CSR graph (O(N+E)), current and next full rank vectors (O(N)), and its local update array (O(N/P)); thus memory is O(N+E) per process and O(P(N+E)) across processes, not sharded O((N+E)/P) memory. Every iteration performs two scalar sum all-reductions and one all-gather that assembles N rank values on each process. Synchronization and data movement can limit scaling. A more detailed communication time depends on MPI collective algorithms, process placement, network topology, and message sizes; the measured single-machine runs do not establish a universal network-cost formula.

Graph construction and process startup are outside the timed region. The MPI timer starts after an MPI_Barrier, includes the iterative computation and collectives, and each run reports the maximum elapsed time across processes (timer and reduction (c/mpi_pagerank.c)).

#define _POSIX_C_SOURCE 200809L
#include "shared_graph.h"

#include <time.h>

static double monotonic_seconds(void)
{
    struct timespec ts;
    if (clock_gettime(CLOCK_MONOTONIC, &ts) != 0)
        return 0.0;
    return (double)ts.tv_sec + (double)ts.tv_nsec * 1e-9;
}

int main(int argc, char **argv)
{
    PRCase c;
    PRGraph graph = {0};
    double *rank, *next;
    double final_error = 0.0;
    size_t iterations = 0;
    int success = 0;
    if (!pr_parse_case(argc, argv, &c)) {
        pr_usage(argv[0]);
        return EXIT_FAILURE;
    }
    if (!pr_graph_build(&graph, &c) || !pr_graph_valid(&graph)) {
        fprintf(stderr, "Unable to construct graph\n");
        return EXIT_FAILURE;
    }
    rank = pr_initial_ranks(graph.n);
    next = pr_rank_vector(graph.n);
    if (rank == NULL || next == NULL) {
        fprintf(stderr, "Unable to allocate rank vectors\n");
        free(rank); free(next); pr_graph_free(&graph);
        return EXIT_FAILURE;
    }
    const double start = monotonic_seconds();
    for (size_t iter = 1; iter <= PR_MAX_ITERATIONS; ++iter) {
        double dangling = 0.0, error = 0.0;
        for (size_t v = 0; v < graph.n; ++v)
            if (graph.out_degree[v] == 0) dangling += rank[v];
        const double base = (1.0 - PR_DAMPING) / (double)graph.n +
                            PR_DAMPING * dangling / (double)graph.n;
        for (size_t v = 0; v < graph.n; ++v) {
            double incoming = 0.0;
            for (size_t p = graph.in_offsets[v]; p < graph.in_offsets[v + 1]; ++p) {
                const size_t src = (size_t)graph.in_sources[p];
                incoming += rank[src] / (double)graph.out_degree[src];
            }
            next[v] = base + PR_DAMPING * incoming;
            error += next[v] >= rank[v] ? next[v] - rank[v] : rank[v] - next[v];
        }
        final_error = error;
        { double *tmp = rank; rank = next; next = tmp; }
        iterations = iter;
        if (error < PR_TOLERANCE) { success = 1; break; }
    }
    const double elapsed = monotonic_seconds() - start;
    pr_print_result(&graph, iterations, elapsed, success, final_error,
                    c.emit_ranks, rank);
    free(rank); free(next); pr_graph_free(&graph);
    return success ? EXIT_SUCCESS : EXIT_FAILURE;
}

#include "shared_graph.h"

#include <mpi.h>

int main(int argc, char **argv)
{
    int rank_id, world_size;
    PRCase c;
    PRGraph graph = {0};
    double *rank = NULL, *next = NULL, *local_values = NULL;
    double final_error = 0.0;
    int *counts = NULL, *displacements = NULL;
    size_t begin, end, local_n, iterations = 0;
    int success = 0;

    if (MPI_Init(&argc, &argv) != MPI_SUCCESS)
        return EXIT_FAILURE;
    if (MPI_Comm_rank(MPI_COMM_WORLD, &rank_id) != MPI_SUCCESS ||
        MPI_Comm_size(MPI_COMM_WORLD, &world_size) != MPI_SUCCESS)
        MPI_Abort(MPI_COMM_WORLD, EXIT_FAILURE);
    if (!pr_parse_case(argc, argv, &c)) {
        if (rank_id == 0) pr_usage(argv[0]);
        MPI_Finalize();
        return EXIT_FAILURE;
    }
    /* Replicated deterministic graph: each rank stores the same incoming CSR,
     * and owns only a contiguous range of vertices for each update. */
    if (!pr_graph_build(&graph, &c) || !pr_graph_valid(&graph)) {
        if (rank_id == 0) fprintf(stderr, "Unable to construct graph\n");
        MPI_Abort(MPI_COMM_WORLD, EXIT_FAILURE);
    }
    if (world_size <= 0 || graph.n > (size_t)INT_MAX) {
        if (rank_id == 0) fprintf(stderr, "Graph partition exceeds MPI count limits\n");
        MPI_Abort(MPI_COMM_WORLD, EXIT_FAILURE);
    }
    begin = graph.n * (size_t)rank_id / (size_t)world_size;
    end = graph.n * (size_t)(rank_id + 1) / (size_t)world_size;
    local_n = end - begin;
    rank = pr_initial_ranks(graph.n);
    next = pr_rank_vector(graph.n);
    local_values = local_n > SIZE_MAX / sizeof(*local_values) ? NULL :
        (double *)malloc((local_n == 0 ? 1 : local_n) * sizeof(*local_values));
    if ((size_t)world_size > SIZE_MAX / sizeof(*counts) ||
        (size_t)world_size > SIZE_MAX / sizeof(*displacements))
        MPI_Abort(MPI_COMM_WORLD, EXIT_FAILURE);
    counts = (int *)malloc((size_t)world_size * sizeof(*counts));
    displacements = (int *)malloc((size_t)world_size * sizeof(*displacements));
    if (rank == NULL || next == NULL || local_values == NULL || counts == NULL || displacements == NULL) {
        fprintf(stderr, "Rank %d: unable to allocate rank vectors\n", rank_id);
        MPI_Abort(MPI_COMM_WORLD, EXIT_FAILURE);
    }
    for (int p = 0; p < world_size; ++p) {
        const size_t first = graph.n * (size_t)p / (size_t)world_size;
        const size_t last = graph.n * (size_t)(p + 1) / (size_t)world_size;
        if (last - first > (size_t)INT_MAX || first > (size_t)INT_MAX) {
            if (rank_id == 0) fprintf(stderr, "MPI count/displacement overflow\n");
            MPI_Abort(MPI_COMM_WORLD, EXIT_FAILURE);
        }
        counts[p] = (int)(last - first);
        displacements[p] = (int)first;
    }

    if (MPI_Barrier(MPI_COMM_WORLD) != MPI_SUCCESS)
        MPI_Abort(MPI_COMM_WORLD, EXIT_FAILURE);
    const double start = MPI_Wtime();
    for (size_t iter = 1; iter <= PR_MAX_ITERATIONS; ++iter) {
        double local_dangling = 0.0, dangling = 0.0;
        double local_error = 0.0, error = 0.0;
        for (size_t v = begin; v < end; ++v)
            if (graph.out_degree[v] == 0) local_dangling += rank[v];
        /* Collective order is identical on all ranks: dangling sum, rank
         * all-gather, then global L1 sum. */
        if (MPI_Allreduce(&local_dangling, &dangling, 1, MPI_DOUBLE, MPI_SUM, MPI_COMM_WORLD) != MPI_SUCCESS)
            MPI_Abort(MPI_COMM_WORLD, EXIT_FAILURE);
        const double base = (1.0 - PR_DAMPING) / (double)graph.n +
                            PR_DAMPING * dangling / (double)graph.n;
        for (size_t v = begin; v < end; ++v) {
            double incoming = 0.0;
            for (size_t p = graph.in_offsets[v]; p < graph.in_offsets[v + 1]; ++p) {
                const size_t src = (size_t)graph.in_sources[p];
                incoming += rank[src] / (double)graph.out_degree[src];
            }
            local_values[v - begin] = base + PR_DAMPING * incoming;
        }
        /* Gather into a distinct receive vector (no overlapping MPI buffers),
         * making all remote new ranks available for the next iteration. */
        if (MPI_Allgatherv(local_values, (int)local_n, MPI_DOUBLE, next, counts,
                           displacements, MPI_DOUBLE, MPI_COMM_WORLD) != MPI_SUCCESS)
            MPI_Abort(MPI_COMM_WORLD, EXIT_FAILURE);
        for (size_t v = begin; v < end; ++v)
            local_error += next[v] >= rank[v] ? next[v] - rank[v] : rank[v] - next[v];
        if (MPI_Allreduce(&local_error, &error, 1, MPI_DOUBLE, MPI_SUM, MPI_COMM_WORLD) != MPI_SUCCESS)
            MPI_Abort(MPI_COMM_WORLD, EXIT_FAILURE);
        final_error = error;
        { double *tmp = rank; rank = next; next = tmp; }
        iterations = iter;
        if (error < PR_TOLERANCE) { success = 1; break; }
    }
    {
        const double local_elapsed = MPI_Wtime() - start;
        double elapsed = 0.0;
        if (MPI_Reduce(&local_elapsed, &elapsed, 1, MPI_DOUBLE, MPI_MAX, 0, MPI_COMM_WORLD) != MPI_SUCCESS)
            MPI_Abort(MPI_COMM_WORLD, EXIT_FAILURE);
        if (rank_id == 0)
            pr_print_result(&graph, iterations, elapsed, success, final_error,
                            c.emit_ranks, rank);
    }
    free(rank); free(next); free(local_values); free(counts); free(displacements);
    pr_graph_free(&graph);
    MPI_Finalize();
    return success ? EXIT_SUCCESS : EXIT_FAILURE;
